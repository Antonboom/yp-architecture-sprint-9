| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| **F** | **Функциональные (Functionality)** ||
|     | Сайт: ||
|     | На сайте новый клиент видит список доступных депозитов с актуальными ставками ||
|     | На сайте клиент может подать заявку на депозит, оставив свой номер телефона и Ф.И.О. ||
|     | Интернет-банк:    |              |
|     | Клиент видит список доступных депозитов с актуальными ставками и персонализированные ставки лично для него ||
|     | Указав счёт и сумму депозита, клиент может подать заявку на открытие депозита ||
|     | Заявка на открытие депозита должна быть подтверждена через СМС-код ||
|     | Общее: ||
|     | Сотрудники бекофиса могут управлять ставками по депозитам ||
|     | Менеджер кол-центра видит оставленные заявки на депозит и может совершать обратные звонки ||
| **U** | **Удобство использования (Usability)** ||
|     | Бизнес ожидает, что интерфейс работы будет максимально удобным для клиента ||
|     | Интерфейс соответствует корпоративной дизайн-системе | Пользователи при работе должны видеть привычные цвета и брендированные элементы |
| **R** | **Надёжность (Reliability)** ||
|     | Доступность системы 99.9%, работа 24/7 ||
|     | Изоляция интернет-банка от API АБС для устойчивости | В новом процессе депозитов |
|	  | В случае сбоев в ЦОД необходимо, чтобы сервисы интернет-банка были доступны и выдерживали требуемую нагрузку | У банка есть резервный ЦОД, в случае сбоя можно переключиться на него |
|     | Равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД ||
| **P** | **Производительность (Performance)** ||
|     | Быстрый отклик UI (миллисекунды) ||
|     | Справочнные данные не должны загружаться более 1 сек ||
| **S** | **Поддерживаемость (Supportability)** |              |
|       | Использовать существующие технологии (MS SQL, Oracle, .NET, React) ||
|       | Возможность расширения на мобильное приложение | Прогнозируем естественную эволюцию бизнес-хотелок |
| **+R** | **+ Ограничения (Restricitions)**      |              |
|        | Сайт и интернет-банк используют HTTPS / шифрование трафика ||
|        | Если нужны очереди сообщений, то лучше использовать Kafka на перспективу | |
|        | Возможен перевод интернет-банка на микросервисы (в рамках депозита) | |
|        | АБС может масштабироваться только вертикально из-за своей базы данных | |
|        | Отказ от доработки ядра интернет-банка подрядчиком ||
